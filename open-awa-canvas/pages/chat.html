在大规模并发场景下优化 LLM 推理性能，需要从以下几个核心维度进行系统性优化：

1. KV Cache 优化

KV Cache 是 Transformer 推理中内存消耗的主要来源。优化策略包括：

  • PagedAttention：将 KV Cache 分页管理，按需分配内存，避免预分配导致的浪费（vLLM 核心技术）
  • Prefix Caching：对系统提示词和共享前缀进行缓存复用，避免重复计算
  • Token 压缩：对注意力分数低的 token 进行裁剪或量化，减少缓存占用

2. 批处理推理策略

  • Continuous Batching：动态批处理，请求到达即刻加入批次，完成后立即释放槽位
  • Orca / Sarathi Scheduling：基于迭代级别的调度算法，按 chunk 粒度调度请求

3. 量化技术

  • INT8/INT4 量化：GPTQ、AWQ、SmoothQuant 等方法可在几乎不损失精度的前提下减少 50%-75% 的显存占用
  • Floating Point 量化：FP8 (E4M3/E5M2) 在 H100/RTX 4090 上有原生硬件支持

4. 模型并行与分布式推理

  • Tensor Parallelism：将模型权重分片到多张 GPU 上并行计算
  • Pipeline Parallelism：按层分割模型到不同 GPU，流水线式推进
  • Speculative Decoding：用小模型生成候选 token，大模型并行验证，提升吞吐
