Navigation Architecture 2026

从页面迷宫，变成五个工作域。

Open-AwA 不再让用户理解二十多个技术模块。三端共享同一棵任务树，再分别投影为 Web 领域轨道、Electron 桌面工作区和 Android Material 3 自适应导航。

已批准方案 A3 直接淘汰重复页面和重复目的地。旧 URL 只在两个稳定版本内重定向，不再渲染旧页面。
01 / ASSIST

助手

当前对话、会话历史和上下文。角色、记忆、声音只在这里被选择，不在这里被管理。

02 / BUILD

工作台

项目、编辑器和 ACP Agents 共享同一项目上下文，替代工作区、编码、Vibe Coding 三个孤岛。

03 / RUN

自动化

流程、计划、执行者和运行记录构成一个闭环。讨论下沉到具体运行详情。

04 / EQUIP

资源库

能力、角色、知识和声音统一管理。“已安装 / 发现”只是同一列表的视图状态。

05 / OBSERVE

动态

概览、收件箱、用量和系统状态。渠道配置回到设置，不与消息消费混在一起。
