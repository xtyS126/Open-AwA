| 维度 | Critical | High | Medium | Low | 小计 |
|------|----------|------|--------|-----|------|

最严重的发现是 `/api/preview` 反向代理构成 SSRF + 认证绕过链（未认证可枚举本地端口并访问后端任意 API），CSRF 中间件对非 JWT 格式 Bearer token 的豁免可被伪造绕过，以及插件市场下载器缺少私有 IP 拦截。性能层面最严重的是 BM25 索引 O(N²) 全量重算、`experiences.py` 全部 async 路由直接同步 DB 阻塞事件循环。

## P0 立即修复（Critical）

### SEC-01 preview_proxy SSRF + 认证绕过链

- **Rule**: FASTAPI-SSRF-001 / FASTAPI-AUTH-001 / ATT-01
- **Location**: [backend/api/routes/preview_proxy.py](file:///d:/代码/Open-AwA/backend/api/routes/preview_proxy.py)
- **Evidence**: `proxy_to_local` 路由签名缺少 `Depends(get_current_user)`；端口范围 1024-65535 全开放；path 无白名单
- **Impact**: 未认证攻击者可探测本地所有端口、访问 `127.0.0.1:8000/api/billing/credentials` 绕过认证窃取凭据
- **Fix**: 添加 `Depends(get_current_user)`；端口白名单限制为已知开发服务器端口；path 白名单仅允许前端路径

### SEC-02 CSRF 中间件 Bearer 豁免绕过

- **Rule**: FASTAPI-CSRF-001 / ATT-03
- **Location**: [backend/main.py:916-927](file:///d:/代码/Open-AwA/backend/main.py#L916-L927)
- **Evidence**: 通过 `bearer_token.count(".") == 2` 启发式判断是否为 JWT，非 JWT 格式直接豁免 CSRF
- **Impact**: 攻击者构造 `Authorization: Bearer fakeapikey123` + 受害者 Cookie 自动发送，绕过 CSRF 完成状态变更操作
- **Fix**: 仅当 Cookie 中存在 JWT 时才需要 CSRF 校验；或仅当 Bearer 实际命中数据库 API Key 时才豁免

### SEC-03 生产环境默认/自动生成密钥

- **Rule**: FASTAPI-DEPLOY-001 / FASTAPI-DEPLOY-002 / ATT-04
- **Location**: [backend/config/settings.py](file:///d:/代码/Open-AwA/backend/config/settings.py)
- **Evidence**: 开发环境硬编码默认密钥 `openawa-dev-jwt-default-32chars-minimum!!`；生产环境缺失密钥时自动生成仅记录 CRITICAL 日志仍允许启动
- **Impact**: 攻击者获取源码即可伪造 JWT、解密 `enc2:` 凭据；生产部署遗漏配置时静默使用随机密钥导致重启后旧 token 失效、API Key 永久无法解密
- **Fix**: 生产环境任一密钥缺失直接 `raise RuntimeError` 拒绝启动；删除硬编码默认值

### SEC-04 Inbox 全局共享存储 IDOR

- **Rule**: FASTAPI-AUTHZ-001 / C-01
- **Location**: [backend/api/routes/inbox.py](file:///d:/代码/Open-AwA/backend/api/routes/inbox.py)
- **Evidence**: 模块级 `_inbox_store: list[dict]` 全局共享，未按 user_id 隔离
- **Impact**: 任意已认证用户可读取/删除其他用户消息
- **Fix**: 改为 `dict[user_id, list[dict]]` 或迁移数据库表，所有端点注入 `current_user` 并过滤

### SEC-05 Workspace 端点完全缺失认证

- **Rule**: FASTAPI-AUTHZ-001 / C-02
- **Location**: [backend/api/routes/workspace.py](file:///d:/代码/Open-AwA/backend/api/routes/workspace.py)
- **Evidence**: 所有端点未声明 `Depends(get_current_user)`，仅依据 workspace_id 操作
- **Impact**: 任意能访问路由的调用者可创建/读取/修改/删除任意用户工作区
- **Fix**: 所有端点强制注入 `current_user`，校验 `workspace.user_id == current_user.id`

### SEC-06 微信 WebSocket CSWSH

- **Rule**: FASTAPI-WS-001 / C-03
- **Location**: [backend/api/routes/weixin.py](file:///d:/代码/Open-AwA/backend/api/routes/weixin.py)
- **Evidence**: WebSocket 端点无 Origin 校验；token 通过 URL query 传递
- **Impact**: 跨站 WebSocket 劫持；token 泄露到日志/Referer/浏览器历史
- **Fix**: accept 前校验 Origin 白名单；token 改为 Sec-WebSocket-Protocol 子协议传递

### PERF-01 BM25 索引 O(N²) 全量重算

- **Category**: 重复计算
- **Location**: [backend/memory/bm25_retriever.py:43](file:///d:/代码/Open-AwA/backend/memory/bm25_retriever.py#L43)
- **Evidence**: `self._avg_doc_length = sum(self._doc_lengths.values()) / self._total_docs` 每次索引都全量求和
- **Impact**: 万级文档索引重建从毫秒退化为秒级甚至分钟级
- **Fix**: 维护增量变量 `_total_doc_length_sum`，O(1) 计算

### PERF-02 experience_manager 多个 async 方法直接同步 DB 阻塞事件循环

- **Category**: 事件循环阻塞
- **Location**: [backend/memory/experience_manager.py:541-645](file:///d:/代码/Open-AwA/backend/memory/experience_manager.py#L541-L645)
- **Evidence**: `archive_low_quality_experiences`/`mark_for_review`/`get_experience_stats`/`delete_experience` 直接 `self.db.query` 而非 `asyncio.to_thread`
- **Impact**: GET `/api/experiences/stats` 阻塞事件循环；commit 锁住 SQLite WAL 数百毫秒
- **Fix**: 拆分为 `_xxx_sync` + `asyncio.to_thread` 包装，使用独立 session

### PERF-03 experiences.py 全部 async 路由直接同步 DB + GET 写库

- **Category**: 事件循环阻塞
- **Location**: [backend/api/routes/experiences.py](file:///d:/代码/Open-AwA/backend/api/routes/experiences.py)
- **Evidence**: 所有 `async def` 路由直接 `db.query/db.commit`；GET 接口 `usage_count += 1; db.commit()`
- **Impact**: 所有 experiences 路由阻塞事件循环；高频读取引发 SQLite WAL 锁竞争
- **Fix**: 路由内 DB 操作 `asyncio.to_thread` 包装；GET 不写 usage_count；stats 用 SQL 聚合

## 可利用攻击链

1. **链 A: SSRF → 认证绕过 → 完全接管**
   `SEC-07 (插件 SSRF 探测内网) → SEC-01 (preview 代理绕过认证) → SEC-11 (获取 API 拓扑) → SEC-03 (默认密钥伪造 JWT) → 完全管理员权限`

2. **链 B: CSRF → 状态变更**
   `SEC-02 (CSRF 绕过) → 受害者已登录 → 转账/改密/添加管理员 → SEC-03 (默认密钥直接伪造 JWT)`

3. **链 C: 未认证 → 日志污染 → DoS**
   `SEC-19 (未认证日志注入) → 磁盘耗尽 → 服务 DoS`

4. **链 D: MCP IDOR → 凭据泄露**
   `SEC-08 (MCP 跨用户) → 读取他人 server env → 获取 API Key → 横向移动`

5. **链 E: PTY → 任意命令执行**
   `SEC-20 (PTY 黑名单绕过) → python -c 执行任意代码 → 数据窃取/破坏`
