# 🐍 零基础 Python 3 个月学习路线规划

> 适用对象：编程零基础新人  
> 总时长：约 12 周（3 个月）  
> 建议投入：每天 1.5 ~ 2 小时  
> 核心理念：**先动手、再理解、多做项目**

---

## 📅 第一阶段：基础入门（第 1 ~ 4 周）

### 🎯 学习目标
- 理解编程的基本概念（变量、数据类型、条件、循环、函数）
- 能够独立编写 50 ~ 100 行的小脚本
- 熟悉 Python 开发环境与基础调试方法

### 📚 核心知识点

| 周次 | 知识点 | 说明 |
|:---:|:---|:---|
| 第 1 周 | **环境搭建与基础语法** | 安装 Python、选 IDE（推荐 VS Code / PyCharm 社区版）、Hello World、注释、缩进规则 |
| 第 2 周 | **变量与数据类型** | `int` / `float` / `str` / `bool`、类型转换、输入输出 (`input()` / `print()`) |
| 第 3 周 | **条件判断与循环** | `if` / `elif` / `else`、`for` 循环、`while` 循环、`break` / `continue`、嵌套循环 |
| 第 4 周 | **基础数据结构** | `list`（列表）、`tuple`（元组）、`dict`（字典）、`set`（集合）、索引与切片 |

### 🔧 推荐练习 / 小项目

1. **猜数字游戏** — 程序随机生成一个数字，用户猜，提示"大了/小了"
2. **简易计算器** — 支持加减乘除，循环等待用户输入表达式
3. **学生成绩管理** — 用列表或字典存储多个学生成绩，计算平均分、最高分、及格率
4. **九九乘法表** — 用嵌套循环打印完整乘法表

> 💡 **零基础提示**：前两周如果觉得吃力很正常，**每个代码示例都亲手敲一遍**，不要复制粘贴。

---

## 📅 第二阶段：进阶提升（第 5 ~ 8 周）

### 🎯 学习目标
- 掌握函数、模块化编程、文件操作
- 理解面向对象编程（OOP）的核心思想
- 能用 Python 处理实际数据（文件读写 + 基础数据处理）
- 学会使用第三方库

### 📚 核心知识点

| 周次 | 知识点 | 说明 |
|:---:|:---|:---|
| 第 5 周 | **函数与作用域** | 定义函数 (`def`)、参数（位置参数 / 默认参数 / 关键字参数）、返回值、全局变量与局部变量、`lambda` 表达式 |
| 第 6 周 | **文件操作与异常处理** | 读/写文件 (`open` / `with`)、`try` / `except` / `finally`、处理常见异常类型 |
| 第 7 周 | **面向对象编程（OOP）入门** | 类与对象、`__init__` 构造方法、实例方法 / 类方法 / 静态方法、封装、继承、多态（简单理解即可） |
| 第 8 周 | **模块与常用标准库** | `import` 导入、`pip` 安装第三方库、`random` / `math` / `datetime` / `os` / `json` 模块 |

### 🔧 推荐练习 / 小项目

1. **日记应用** — 支持写入日期、内容到 txt 文件，能按日期查询历史记录
2. **通讯录管理系统** — 用字典存储联系人（姓名 + 电话 + 邮箱），支持增删改查，数据保存到 JSON 文件
3. **单词记忆小工具** — 读取单词本文件，随机出题测试，记录正确率
4. **简单的图书类设计** — 用类表示图书、书架，实现借书/还书/查询功能

> 💡 **零基础提示**：OOP 概念如果一时理解不透彻，先**模仿代码写，再逐步理解**，不要卡在这里太久。

---

## 📅 第三阶段：项目实战（第 9 ~ 12 周）

### 🎯 学习目标
- 综合运用前 8 周知识，独立完成 2 ~ 3 个完整项目
- 学会使用 Git 做版本管理（基础操作）
- 初步了解 Web 开发或数据分析方向（二选一）
- 培养阅读文档和搜索解决方案的能力

### 📚 核心知识点

| 周次 | 知识点 | 说明 |
|:---:|:---|:---|
| 第 9 周 | **Git 基础 + 项目规范** | `git init` / `add` / `commit` / `push`、README 编写、项目目录结构组织 |
| 第 10 周 | **方向一：Web 开发入门（Flask）** | 路由、模板渲染 (`Jinja2`)、GET/POST、表单处理、简单数据库操作 (SQLite) |
| 第 10 周 | **方向二：数据分析入门（Pandas）** | 读取 CSV/Excel、DataFrame 操作、数据清洗、简单的可视化 (`matplotlib`) |
| 第 11 周 | **综合项目（上）** | 选定项目、搭建框架、实现核心功能 |
| 第 12 周 | **综合项目（下）** | 完善功能、调试测试、撰写 README、打包或部署 |

### 🔧 推荐实战项目（三选一或全做）

#### 项目 A：个人博客系统（Web 方向）
- **技术栈**：Flask + HTML/CSS + SQLite
- **功能**：用户注册登录、发布/编辑/删除文章、文章列表与详情页、按标签分类
- **亮点**：可以部署到免费平台（如 Render / Vercel / 阿里云免费试用）

#### 项目 B：疫情/股票/天气数据分析（数据分析方向）
- **技术栈**：Pandas + Matplotlib + Jupyter Notebook
- **功能**：从公开 API 获取数据、数据清洗、生成趋势图、统计报表
- **亮点**：学习如何调用 API、数据可视化、输出图文报告

#### 项目 C：命令行任务管理器（全栈基本功方向）
- **技术栈**：纯 Python + JSON 存储
- **功能**：添加/完成/删除/搜索任务、设置优先级与截止日期、数据持久化
- **亮点**：不依赖任何框架，巩固 OOP 和文件操作，可作为 Git 仓库展示

> 💡 **零基础提示**：第 10 周的两个方向**选一个即可**。建议根据自己的兴趣选择：喜欢做界面/网页选 Web，喜欢跟数字/图表打交道选数据分析。

## 📎 附：常见问题与心态建议

1. **"我记不住语法怎么办？"** → 不需要刻意背，**多写自然就记住了**，随时查文档是正常操作
2. **"遇到报错看不懂怎么办？"** → 复制错误信息到搜索引擎（推荐用英文搜 Stack Overflow），90% 的问题别人都遇到过
3. **"学了一个月感觉还是不会写？"** → 这是正常的"新手墙"，说明需要**增加练习量**，从模仿开始
4. **"要不要记笔记？"** → **强烈建议**，但不要抄书，记自己踩过的坑和关键代码片段
5. **"学完后能达到什么水平？"** → 能独立写 200 ~ 500 行的工具类程序，具备继续自学进阶方向（Web / 数据分析 / 自动化）的基础

---

> 🚀 **最后的话**：编程不是看会的，是**敲会的**。3 个月时间不长不短，坚持每天动手写代码，第 12 周回头看第 1 周的自己，你会惊讶于自己的进步。加油！
