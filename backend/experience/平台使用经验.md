## 二、记忆系统使用心得

1. **存入内容应是提炼后的事实**（≤200 字），不要存对话原文 —— 后端会自动：
   - PII 脱敏（API key / 私钥 / 身份证 → `[REDACTED]`）
   - 向量去重（相似度 > 0.85 自动合并到已有记忆，返回 `deduplicated` 标识）
2. **`memory_recall` 会动态更新置信度**：五因子加权（来源权重 0.3 + 内容完整度 0.25 + 时效性 0.2 + 去重命中减分 0.15 + access_count 强化 0.1），每次检索 access_count +1。
3. **`memory_forget` 是软删除**：标记 deprecated，不注入上下文也不再检索返回，但 DB 行保留用于审计；物理删除需联系管理员。
4. 新对话开始时系统会自动注入最近 20 条短期记忆，无需手动检索。
